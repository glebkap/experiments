# 🎬 H.265 HLS Video Player

Универсальный веб-плеер для воспроизведения HLS видео с кодеком H.265, работающий во всех современных браузерах.

## 🚀 Быстрый старт

### 1. Запуск локально

Для запуска плеера локально вам нужен простой HTTP сервер (браузеры блокируют некоторые функции при открытии файлов через `file://`).

#### Вариант 1: Python HTTP сервер
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

#### Вариант 2: Node.js HTTP сервер
```bash
# Установить serve глобально
npm install -g serve

# Запустить сервер
serve -p 8000
```

#### Вариант 3: PHP встроенный сервер
```bash
php -S localhost:8000
```

### 2. Открыть в браузере

После запуска сервера откройте в браузере:
```
http://localhost:8000
```

## 🌐 Поддержка браузеров

### HLS (HTTP Live Streaming)
| Браузер | Нативная поддержка | Через hls.js |
| ------- | ------------------ | ------------ |
| Safari  | ✅ Да               | ✅ Да         |
| Chrome  | ❌ Нет              | ✅ Да         |
| Firefox | ❌ Нет              | ✅ Да         |
| Edge    | ❌ Нет              | ✅ Да         |

### H.265/HEVC кодек
| Браузер | Поддержка  | Примечания                     |
| ------- | ---------- | ------------------------------ |
| Safari  | ✅ Да       | Полная поддержка на macOS/iOS  |
| Chrome  | ⚠️ Частично | Только на некоторых платформах |
| Firefox | ❌ Нет      | Не поддерживается              |
| Edge    | ⚠️ Частично | Зависит от системы             |

## 📝 Как использовать

1. **Вставьте URL HLS потока**
   - Введите ссылку на `.m3u8` файл в поле "URL источника видео"
   - Нажмите Enter или кнопку "Загрузить видео"

2. **Управление воспроизведением**
   - ▶️ Воспроизвести/Пауза
   - ⏹️ Остановить воспроизведение
   - 🔇 Включить/выключить звук

3. **Мониторинг**
   - Следите за статусом в реальном времени
   - Просматривайте подробные логи внизу страницы
   - Проверяйте поддержку форматов

## 🔧 Конфигурация

### Настройки hls.js

В файле `script.js` можно изменить настройки hls.js:

```javascript
hls = new Hls({
    debug: true,                // Отладочные сообщения
    enableWorker: true,         // Web Workers для лучшей производительности
    lowLatencyMode: false,      // Режим низкой задержки
    backBufferLength: 90        // Размер буфера в секундах
});
```

## 🐛 Отладка и решение проблем

### Частые проблемы

1. **"Видео не загружается"**
   - Проверьте CORS настройки сервера с видео
   - Убедитесь, что URL правильный
   - Посмотрите логи в консоли браузера

2. **"H.265 не воспроизводится"**
   - Проверьте поддержку в статусе плеера
   - Попробуйте в Safari (лучшая поддержка H.265)
   - Рассмотрите использование H.264 для большей совместимости

3. **"CORS ошибки"**
   - Сервер с видео должен отправлять правильные CORS заголовки
   - Для разработки используйте браузер с отключенными CORS проверками

### Логирование

Плеер ведет подробные логи:
- 🔵 **INFO** - общая информация
- 🟡 **WARN** - предупреждения
- 🔴 **ERROR** - ошибки
- 🟢 **SUCCESS** - успешные операции

Логи также дублируются в консоль браузера (F12).
