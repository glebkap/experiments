# 🎬 H.265 HLS Player с goldvideo fallback

Веб-плеер для воспроизведения HLS плейлистов с кодеком H.265 (HEVC). Автоматически определяет нативную поддержку H.265 в браузере и использует goldvideo/h265player как fallback для браузеров без нативной поддержки.

## 🚀 Быстрый старт

### 1. Запуск локально

Для запуска плеера локально используйте HTTP сервер (браузеры блокируют некоторые функции при открытии файлов через `file://`).

#### Вариант 1: Python HTTP сервер (рекомендуется)
```bash
# Python 3
python3 cors_server.py --port 8080 --host 0.0.0.0

# Или простой сервер
python3 -m http.server 8000
```

#### Вариант 2: Node.js HTTP сервер
```bash
# Установить зависимости
npm install

# Запустить сервер
npm start
```

### 2. Открыть в браузере

После запуска сервера откройте в браузере:
```
http://localhost:8080
```

### Стратегия воспроизведения
1. **Проверка нативной поддержки H.265** - для Safari и некоторых других браузеров
2. **Проверка HLS манифеста** - анализ доступных кодеков в плейлисте
3. **Автоматическое переключение** - использование goldvideo/h265player для H.265 контента при отсутствии нативной поддержки
4. **Fallback к H.264** - воспроизведение H.264 потоков через стандартный video элемент

### Требования к браузеру
- **WebAssembly**: Для работы goldvideo/h265player fallback
- **ES6 модули**: Для загрузки зависимостей
- **Canvas 2D**: Для рендеринга видео в goldvideo плеере
- **Web Workers**: Для оптимальной производительности

## 📝 Как использовать

### 1. Загрузка HLS плейлиста
- Введите URL `.m3u8` файла в поле ввода
- Плеер автоматически загрузит и проанализирует манифест
- Выберет оптимальное качество для воспроизведения

### 2. Управление воспроизведением
- ▶️ **Воспроизвести/Пауза** - старт/остановка воспроизведения
- ⏹️ **Остановить** - остановка и сброс позиции
- 🔇 **Звук** - управление аудио
- 📸 **Кадр** - сохранение текущего кадра как PNG

### 3. Мониторинг состояния
- **Статус плеера** - текущее состояние загрузки/воспроизведения
- **Статус декодера** - показывает используемый метод декодирования:
  - "H.265 поддерживается (нативно)" - браузер поддерживает H.265 нативно
  - "H.265 поддерживается (goldvideo)" - используется goldvideo/h265player fallback
  - "Только H.264" - доступно только воспроизведение H.264
- **Формат видео** - информация о текущем потоке
- **Текущий источник** - URL загруженного плейлиста

## 🔄 goldvideo/h265player Fallback

### Как работает автоматическое переключение

1. **При инициализации плеера:**
   - Проверяется нативная поддержка H.265 в браузере
   - Проверяется доступность goldvideo/h265player библиотеки
   - Устанавливается стратегия воспроизведения

2. **При загрузке HLS манифеста:**
   - Анализируется список доступных потоков
   - Определяются используемые видеокодеки
   - Если обнаружен H.265 контент без нативной поддержки, активируется goldvideo fallback

3. **Переключение плеера:**
   - Стандартный `<video>` элемент скрывается
   - Активируется `<canvas>` элемент для goldvideo рендеринга
   - Все команды управления перенаправляются на goldvideo API

### Особенности goldvideo режима

- **WebAssembly декодирование** - использует FFmpeg через WASM для H.265
- **Canvas рендеринг** - вывод видео через Canvas 2D
- **Высокое CPU использование** - программное декодирование требует больше ресурсов
- **Поддержка всех браузеров** - работает везде где есть WebAssembly

## 🔧 Конфигурация

### Настройки HLS.js

```javascript
this.hls = new Hls({
    debug: false,               // Отладочные сообщения
    enableWorker: true,         // Web Workers для производительности
    lowLatencyMode: false,      // Режим низкой задержки
    backBufferLength: 90,       // Размер буфера в секундах
    maxBufferLength: 30,        // Максимальный буфер
    maxMaxBufferLength: 600     // Абсолютный максимум буфера
});
```

### Настройки libde265

```javascript
// Инициализация декодера
this.decoder = new libde265.Decoder();

// Настройка параметров декодирования
this.decoder.set_parameter(libde265.DE265_DECODER_PARAM_BOOL, 
                          libde265.DE265_DECODER_PARAM_SUPPRESS_FAULTY_PICTURES, 
                          false);
```

## 🐛 Отладка и решение проблем

### Частые проблемы

1. **"libde265 не загружен"**
   ```
   Решение: Проверьте доступность CDN или используйте локальную копию
   Альтернатива: Загрузите libde265.js с GitHub и разместите локально
   ```

2. **"HLS манифест не загружается"**
   ```
   Причины: CORS ошибки, недоступный URL, неверный формат
   Решение: Проверьте CORS заголовки сервера, используйте cors_server.py для разработки
   ```

3. **"H.265 декодирование медленное"**
   ```
   Причины: Высокое разрешение, слабый CPU, отсутствие Web Workers
   Решение: Используйте меньшее разрешение, включите Web Workers
   ```

4. **"Фрагменты не загружаются"**
   ```
   Причины: Сетевые проблемы, CORS, неверные URL в манифесте
   Решение: Проверьте доступность сегментов, настройте CORS
   ```

### Компоненты системы

- **HLS.js**: Загрузка и парсинг M3U8, управление сегментами
- **libde265**: Декодирование H.265/HEVC в формат YUV
- **HTML5 Video**: Нативное воспроизведение и управление
- **Web Workers**: Асинхронная загрузка данных
- **WebAssembly**: Высокопроизводительное декодирование
- **Canvas API**: Рендеринг декодированных кадров
